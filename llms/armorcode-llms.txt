# ArmorCode

> ArmorCode is a unified exposure and application security posture management (ASPM) platform that consolidates vulnerability and security findings from 350+ security tools into a single control plane. It uses a Context Risk Graph and agentic AI workflows (Anya agents) to prioritize and automate remediation across application, cloud, supply-chain, and AI security. ArmorCode exposes a REST API on app.armorcode.com (US) and eu.armorcode.com (EU) for programmatic access to findings, integrations, and remediation workflows. API access uses bearer API tokens.

## Company
